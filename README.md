# Greater Cincinnati Memory Map

An interactive, memory-first map for learning Cincinnati and the surrounding metro.

## Current study area
Cincinnati neighborhoods plus the surrounding ring including Fairfield, Forest Park, West Chester, Blue Ash, Mason, Loveland, Eastgate and Batavia.

## Features
- Local slang / shorthand filter such as **West Side**, **East Side**, **Uptown**, **Tri-County**, **North Cincy**, and **Eastgate / Clermont**
- Mental-region, distance, direction, and personal-progress filters
- Cincinnati neighborhood boundaries
- Greater Cincinnati municipal boundaries
- Search and click-to-study
- Neighborhood/suburb quiz mode
- Local learning progress saved in the browser

## Data
- Cincinnati neighborhoods: Code for America Click That 'Hood dataset
- Municipal boundaries: State of Ohio GIS
- Base map: OpenStreetMap

Slang and mental-region layers are learning aids and are intentionally approximate rather than official geographic boundaries.

## Run locally
Open `index.html` in a browser, or serve the directory with any static web server.
